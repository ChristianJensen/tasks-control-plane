## Key Patterns

- **Single-file Express app** — all routes defined inline in `src/app.js`
- **In-memory Maps** — `tasks`, `comments`, `subtasks` stored as `Map()` objects with auto-incrementing IDs
- **Helper functions** — `taskWithCount()` enriches task with computed fields; `sortedTasks()` returns position-ordered array
- **Cascade delete** — `DELETE /tasks/:id` removes associated comments and subtasks

## Conventions

- **Naming:** camelCase for variables and functions, kebab-case not used in code
- **Error handling:** Inline `res.status(4xx).json({ error: '...' })` — no centralized error middleware
- **Auth:** `X-User-Id` header for ownership checks (comments only); tasks have no ownership
- **Validation:** Inline in each route handler — no validation library

## Existing Utilities

- `taskWithCount(task)` — enriches task with `commentCount`, `subtaskCount`, `completedSubtaskCount`
- `applyAutoComplete(taskId)` — auto-completes task when all subtasks complete
- `sortedTasks()` — returns tasks sorted by position
- `app._resetStore()` — test helper to clear all data

## Test Infrastructure

- **Framework:** Jest
- **Run command:** `npm test`
- **Fixtures:** None — tests use `app._resetStore()` in `beforeEach` and supertest for HTTP
