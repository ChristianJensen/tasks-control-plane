## Key Patterns

- **Single-file React app** — all components defined in `src/App.jsx` (~1237 lines)
- **State management** — `useState` + `useEffect` with `fetch()` calls to API
- **API URL** — `import.meta.env.VITE_API_URL || 'http://localhost:3001'`
- **Component structure** — inline component functions (PriorityBadge, TaskItem, etc.) within the same file
- **Drag-and-drop** — uses `@dnd-kit/core` and `@dnd-kit/sortable` for task reordering
- **Icon library** — `lucide-react` for icons

## Conventions

- **Naming:** PascalCase components, camelCase functions/variables, JSX extension
- **Styling:** Inline style objects using theme tokens — no CSS modules or Tailwind
- **Error handling:** `try/catch` around fetch calls, error state shown in UI
- **Auth:** Hardcoded `X-User-Id` header sent with comment requests
- **Validation:** Minimal — relies on API validation

## Existing Utilities

- `theme.js` — colors, shadows, card styles, priority/category color maps
- `formatTimestamp()` — formats ISO date strings for display
- `API_URL` constant — centralized API base URL
